# Auto-Marketbuddy

Undercuts your retainer listings.

## Install

Add this repository in Dalamud:

```
https://raw.githubusercontent.com/amarinne/Auto-Marketbuddy/main/repo.json
```

## Use

Open a retainer's sale list, then:

- `/amb preview` — show new prices
- `/amb apply` — set new prices
- `/amb stop` — stop
- `/amb autoretainer off|preview|apply` — run during AutoRetainer
- `/amb` — open the window
